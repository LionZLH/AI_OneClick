# AI 客户端智能选型与一键装机系统 (AI Station Pro)

## 当前可用版本架构 · 2026-10-15

本项目采用 **“在线普通版” + “离线完整版”** 双轨架构，覆盖有网和完全断网/涉密场景：

### 1. 普通版（在线 Web 启动器）
针对有网环境（国内普通网络 / 海外服务），无需提前下载大型离线包：
- **Web 原型入口**：打开 `prototype/index.html`，支持**自由选择配置**与**问卷推荐配置**双模式。
- **一键安装脚本生成**：在确认页点击“生成一键安装脚本”，即可自动生成并下载对应的安装脚本：
  - Windows：导出 `.ps1` 脚本（自动进行 64 位、内存、AVX2 检查，通过 `winget` 静默安装选中的应用，并通过 LM Studio CLI 拉取匹配当前机器内存的 Qwen2.5 模型）。
  - macOS：导出 `.sh` 脚本（检测架构、内存、AVX2，通过 `Homebrew Cask` 静默安装，并通过 LM Studio CLI 拉取模型）。
- **硬件体检工具**：随时点击下载 `check-hardware.ps1` 或 `check-hardware.sh`，在终端运行即可获得当前机器的硬件体检与模型推荐。

### 2. 离线版（网盘完整包分发）
针对完全断网、涉密单位或离线开发机：
- **网盘分档下载**：用户先运行 2KB 的硬件检测小工具，根据终端推荐下载对应版本的网盘离线包：
  - `AI装机-入门版（4-8GB内存）`：附带 Qwen2.5-0.5B (400MB)
  - `AI装机-基础版（8-16GB内存）`：附带 Qwen2.5-1.5B (1.1GB)
  - `AI装机-标准版（16-32GB内存）`：附带 Qwen2.5-7B (4.7GB)
  - `AI装机-完整版（32GB+内存）`：附带 Qwen2.5-14B (9.0GB)
- **自包含安装器**：
  - Windows：运行 `scripts/offline-install.ps1`，自动检测硬件并从 `./apps/` 静默安装 LM Studio、AnythingLLM、Jan、GPT4All，并将 `./models/` 中合适的 GGUF 模型注入对应软件的本地模型目录。
### 3. 原生桌面启动台（极简免装单文件）
- **程序文件**：`AIStation.exe`（编译体积仅 29 KB，零依赖，直接调用系统 .NET 4.8 运行时）。
- **双模支持**：
  - 在线模式：扫描已安装 19 款客户端，未安装应用支持通过 `winget` 一键后台静默下载安装。
  - 离线模式：检测到本地 `apps/` 与 `models/` 时，一键触发全自动断网灌装部署。
  - 内置硬件体检：一键弹窗查看当前 CPU、内存、AVX2 指令集并推导推荐配置。

> 📖 **完整开发与工作交接白皮书**：请查阅 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)，包含详细代码拓扑、编译打包指南、排障避错手记与交接清单。

## 一、 项目背景与商业定位

### 1. 行业痛点
* **认知与查找门槛**：普通用户（职场人、自媒体、学生、传统企业）面对市面上数十款大模型客户端，不知道哪个好用、不知道官网在哪，极易在百度上下载到带有木马流氓捆绑的安装包。
* **环境与硬件恐惧**：配置环境报错、显卡显存不够报错，让小白用户望而却步。
* **伪需求陷阱（避坑结论）**：市场上部分“AI 智能 U 盘”试图通过内置“翻墙梯子”或直接倒卖开源模型牟利，这属于**高风险低壁垒的灰产模式**，极易触碰法律红线且售后成本无限大。

### 2. 本项目核心商业价值
* **定位**：**面向国内用户的正规、阳光、纯绿色的“AI 桌面客户端装机管家 / 分发中心”**。
* **承诺**：
  * **100% 安装就能用**：所有收录软件必须带有成熟图形界面（GUI），彻底干掉没有界面的半成品，双击桌面图标即可直接打字开聊；
  * **0 学习成本**：内置“智能向导问卷”与“全量自主勾选”双入口，小白 2 步匹配，老手一键批量装机；
  * **离线也能打**：针对断网/涉密单位，提供带有轻量开源模型（GGUF）的离线自给自足交付形态。

## 四、 双入口交互设计规范

避免传统问卷的“文字冗长、emoji 泛滥、信息过载”，系统确立**双入口分流架构**：

```text
┌────────────────────────────────────────────────────────┐
│  AI Station Pro           [ 问卷智能推荐 | 全量自主勾选 ] │
└────────────────────────────────────────────────────────┘
```

### 入口 1：【问卷智能推荐】（小白专用，2 步秒选）
* **第 1 题（硬性网络）**：国内普通宽带 / 科学上网 / 完全离线（**点选自动秒切下一题，无需确认**）。
* **第 2 题（核心诉求）**：写代码、读长文档、开会出纪要、公文写作、深度搜索等（**大按钮多选**）。
* **输出机制（互补去重算法）**：针对用户勾选的每一个场景，各挑选 1 款不可替代的行业天花板工具，输出“量身定制配置单”，支持一键安装。

### 入口 2：【全量自主勾选】（老手直通，跳过问卷）
* 0 题目、0 废话，直接平铺展示 20 款客户端分类列表；
* 支持**“全选 / 全清 / 单个勾选”**，底栏实时计算选中数量，支持一键批量静默安装。

## 五、 纯离线环境的端到端部署实操方案

针对拔掉网线、涉密内网等纯离线场景，部署必须解决“没有网怎么拿到软件和模型”的物理现实：

### 1. 物理介质文件排布规范（U 盘 / 移动硬盘）
```text
AI_Offline_Station/ (U盘根目录)
├── 一键安装助手.exe                # 主程序（检测到断网自动进入纯离线模式）
└── offline_assets/                # 离线全自包含资产库
    ├── apps/                      # 离线客户端静默安装包
    │   ├── LM-Studio-Setup.exe
    │   └── AnythingLLM-Setup.exe
    └── models/                    # 【核心】离线大模型权重文件
        └── qwen2.5-1.5b-instruct-q4_k_m.gguf  (约 1.1GB ~ 1.5GB)
```

### 2. 离线模型选型首选：【通义千问 Qwen2.5 - 1.5B (或 3B) GGUF】
* **物理文件格式**：单一的 `.gguf` 量化模型文件；
* **为什么选它**：
  * **体积小**：仅 1.1GB ~ 2.0GB，极易在 U 盘中存放与拷盘；
  * **通杀一切老电脑**：**完全不需要独立显卡**！普通 8GB 内存轻薄办公本，纯靠 CPU 每秒吐字 15~20 个；
  * **中文能力顶级**：日常公文润色、周报撰写、翻译水平极高，几乎不胡说八道。

### 3. 安装器后台自动化 3 步操作（保姆级注入）
1. **静默安装软件**：后台调用 `offline_assets\apps\LM-Studio-Setup.exe /S`，生成桌面图标；
2. **静默注入模型文件**：将 U 盘中的 `qwen2.5-1.5b.gguf` 自动拷贝至软件默认模型路径：
   `C:\Users\%USERNAME%\.cache\lm-studio\models\`；
3. **写入默认配置**：修改软件的配置文件，启动默认加载该模型，**用户断网双击打开软件即可直接打字开聊**。

## 六、 混合部署架构

同一套安装程序源码，自适应支持两种交付形态：

```text
用户点击【安装】
       │
       ▼
检测同级目录是否有 offline_assets/ 安装包？
       ├─► [ 有 ] (离线大包/U盘模式) ──► 0 秒读取本地，断网静默部署与模型注入
       │
       └─► [ 无 ] (轻量在线版模式)   ──► 从国内高速官方源实时下载并静默安装
```

* **15MB 在线版**：官网/社群免费分发，用户秒下载，不耗费自己服务器带宽；
* **5GB 离线 U 盘版**：硬件或网盘高价值交付，内置模型与软件全自包含，断网即插即用。

## 七、 项目工程目录结构与开发路线

```text
AI客户端一键装机助手/
├── README.md                      # [本项目] 商业、合规与技术全案白皮书
├── prototype/                     # [交互原型]
│   └── index.html                 # 极简高质感双入口 Web 交互原型
├── installers/                    # [存放区] 官方安装包 (.exe / .msi)
├── models/                        # [存放区] 离线 GGUF 模型文件 (.gguf)
└── scripts/                       # [脚本区] 打包与静默安装自动化脚本
    ├── build_inno_setup.iss       # Windows Inno Setup 自动化打包脚本
    └── auto_inject_models.py      # 模型静默拷贝与路径注入脚本
```

### 下一步落地开发路线：
1. **采集官方纯净安装包**：下载清单中 20 款官方 `.exe` 放入 `installers/` 文件夹；
2. **下载轻量离线 GGUF 模型**：从 ModelScope 下载 `Qwen2.5-1.5B-GGUF` 放入 `models/` 文件夹；
3. **客户端编译打包**：
   * 路线 A：使用 **Inno Setup** 编译生成单文件 `AI全家桶一键安装.exe`；
   * 路线 B：基于 **Tauri (Rust + Web)** 将 `prototype/index.html` 封装成极轻量的现代化桌面客户端。
